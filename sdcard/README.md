# TaDOOM SD Card Files

Copy all files from this directory to `/apps/at.cavac.tadoom/` on your SD card.

## Required Files
- `doom1.wad` - DOOM 1 shareware WAD (included)
- `prboom.wad` - PrBoom engine data (included, from PrBoom 2.5.0)

## Included Files
- `gm.sf2` - TimGM6mb General MIDI SoundFont for music playback (GPL-2, see `soundfont_license.txt`)

## Optional Files
- `doom.wad` / `doom2.wad` - Full game WADs (if you own them)
- You may replace `gm.sf2` with any GM-compatible SoundFont of your choice
